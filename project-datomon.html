Datomon
Mobil App

Rol: Mobil Geliştirici • Teknoloji: Flutter, Dart, Firebase, SQLite • Yıl: 2025

> overview

Datomon, kurumsal saha çalışanları için geliştirilmiş, yüksek performanslı ve çevrimdışı çalışabilme yeteneğine sahip modern bir mobil uygulamadır. Karmaşık veri setlerini gerçek zamanlı olarak sunucularla senkronize ederken, kullanıcılara pürüzsüz ve tepkisel bir arayüz (UI) sunar. Ekrandaki her piksel ve animasyon, sahadaki operasyonel hızı artırmak üzere özel olarak tasarlandı.



> technical_architecture

Mimari olarak BLoC pattern kullanılarak katmanlı bir yapı inşa edildi. Bu sayede uygulamanın state yönetimi tahmin edilebilir ve test edilebilir hale getirildi. Backend iletişimi için GraphQL kullanılarak sadece ihtiyaç duyulan verilerin çekilmesi sağlandı, bu da ağ trafiğinde %40'a varan bir iyileşme getirdi.

  • [+] Custom Render Object ile 60FPS listeler
  • [+] SQLite tabanlı offline-first senkronizasyon
  • [+] AES-256 tabanlı uçtan uca şifreli depolama
  • [+] Kapsamlı birim ve widget testleri
class DatomonSyncEngine {
  final LocalStorage _storage;
  final ApiClient _api;

  Future<void> syncData() async {
    if (await _hasConnection()) {
      final data = await _storage.getPending();
      await _api.push(data);
      print('Sync Complete');
    }
  }
}
